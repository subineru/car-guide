# 排氣系統核對報告

核對方式:對照 Wikipedia 條目(Exhaust system、Exhaust manifold、Catalytic converter、Lambda sensor、Muffler)。Wikipedia 是通用參考,不是原廠手冊。

| 說法 | 狀態 | 依據 |
|---|---|---|
| 排氣系統把廢氣從引擎導向車外;排氣歧管把多個缸的廢氣集合到一條管;尾管是通到大氣的最後一段 | 已核對 | Wikipedia「Exhaust system」「Exhaust manifold」:collects the exhaust gases from multiple cylinders into one pipe;tailpipe = final length of the exhaust pipe where it vents to open air |
| 觸媒轉換器把一氧化碳與未燃碳氫轉成二氧化碳和水、把氮氧化物還原成氮氣 | 已核對 | Wikipedia「Catalytic converter」 |
| 觸媒的核心是蜂巢結構的陶瓷載體,表面塗有催化材料(washcoat) | 已核對 | Wikipedia「Catalytic converter」:the core is usually a ceramic monolith that has a honeycomb structure |
| 觸媒前後各裝一個氧感知器監測廢氣含氧量,ECU 據此調整噴油 | 已核對 | Wikipedia「Catalytic converter」「Lambda sensor」:before and after the catalytic converter;adjusts the amount of fuel injected |
| 消音器降低排氣聲音;原廠消音器靠反射聲波、共鳴腔利用破壞性干涉消除聲音 | 部分核對 | Wikipedia「Exhaust system」「Muffler」:reflecting sound waves;destructive interference;原文沒有寫「隔板」或「穿孔管」,本圖的內部構造是常見示意 |
| 共鳴器是擴大管徑的管段,讓聲波互相抵消 | 已核對 | Wikipedia「Exhaust system」:sections of pipe that expand to a larger diameter |
| 排氣歧管的各缸出氣依點火順序輪流送出 | 部分核對 | Wikipedia「Exhaust manifold」只在別處提到 firing order,沒有說明這件事;這是從「點火順序」推得的示意 |
| 前驅橫置車的排氣管得在變速箱與轉向機之間繞過 | 示意值 | 本圖佈局的示意假設;實際走法因車型而異 |
