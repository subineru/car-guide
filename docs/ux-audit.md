## 建議但尚未做(需要你決定)
1. **控制列仍有兩排**(步驟列、滑桿與開關列)。選項:把「剖面/氣體顏色/氣流/零件名稱」收進一個「顯示」選單,控制列只剩一排;代價是少一次點擊就能切換。
2. **手機的控制列約佔畫面四成**。可以做成可收合的底部面板(預設只露出步驟按鈕與滑桿)。目前主要目標是桌機/筆電,手機是盡力而為。
3. **小按鈕觸控尺寸**:12 px 的開關、階段標籤在平板上偏小,建議觸控裝置把最小點擊區放大到約 36–44 px。
4. **首次使用提示**:第一次開啟時沒有說明可以拖曳、滾輪、點車頭。可加一次性的小提示(可關閉)。
5. ~~灰色小字對比~~ 已做:次要文字色 `#6b6254` → `#5a5144`,對紙色背景的對比度由 5.2:1 升到 6.8:1。
6. ~~用詞一致~~ 已做:「編號」「場景」「行駛預覽」開關都寫成「名稱 開/關」並以亮暗表示;車門等動作按鈕維持只用亮暗。

## Size budget
claude.ai's preview silently drops very large pages: 784 KB opened, 1076 KB stayed on the splash. `car-guide.html` ships gzip+base64 packed (~400 KB) and `tools/build.py` aborts above 600 KB. Use `--plain` only for tests/debugging.

## 後續調整(依使用者回饋)
- 整車畫面不顯示進度:編號圓圈沒有進度環與狀態色,底部沒有「建議 ▸」提示;進度只在「學習面板 › 全部進度」(區域 → 主題,可重置並復原)。
- 「建議路線」按鈕併入學習面板的「建議順序」分頁;「返回」按鈕拿掉(標題列每一層可點;手機顯示簡短的「‹ 上一層」連結)。
- 頂列「隱藏介面」(H):收起左上說明與右上控制區,頂列與步驟列保留。
- 行駛預覽時車體輕微震動(約 ±2 mm,設定可關);背景音樂 82 BPM,程式合成。
- 學習面板:完成 = 步驟全部播完且理解重點全部勾選;每個主題與區域一個狀態圓圈(空 / 黃色圓餅 / 綠色 ✓);點「前往」後面板保持開啟與原分頁(手機自動關閉),重新繪製時保持捲動位置。
- 場景串流:森林、丘陵、山以區塊串流,隨機生成、不重複;丘陵 12%、山 4% 的速度移動(刻意誇張的視差);路邊反光柱、電線桿、路牌、岩石、灌木;行駛速度 5 m/s,2 秒加速、約 2 秒減速;速度越高視野加寬約 0.9°(與震動同一個開關,並尊重「減少動態效果」)。
