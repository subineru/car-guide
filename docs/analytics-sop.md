# 流量統計(Google Analytics 4)建立 SOP

目的:只統計「有多少人造訪」。**不會**傳送任何學習內容或進度。
適用:部署在 GitHub Pages(`https://<帳號>.github.io/<倉庫>/`)。

## 這個網頁怎麼處理統計(先看懂再設定)
- 程式只在以下條件**全部成立**時才載入 Google 腳本:https 正式網址、不是 claude.ai 預覽、不是本機/測試、倉庫裡有 `ga-id.txt` 且內容是 Measurement ID、瀏覽器沒有開「Do Not Track」、使用者沒有在「設定」關閉。
- 所以:**沒有 `ga-id.txt` = 完全不統計**,和以前一樣離線、不外連。
- 設定面板會出現「匿名流量統計」開關,讀者可以自己關掉(存在自己的瀏覽器)。
- 已關閉 Google signals 與廣告個人化。

## 一、建立 Google Analytics 帳號與資源(約 10 分鐘,你自己做)
1. 用 Google 帳號開啟 <https://analytics.google.com/> → **開始評估**(Start measuring)。
2. **帳號名稱**:隨意(例如 `carlab`);資料共用選項全部可以取消勾選。
3. **資源(Property)**:名稱 `汽車解構室`,時區選 **(GMT+08:00) 台北**,幣別 TWD。
4. 產業類別與規模隨意;**目標**可選「檢視使用者行為」。
5. 平台選 **網站(Web)**,網址填你的 GitHub Pages 網址(例如 `https://你的帳號.github.io/倉庫名/`),串流名稱填 `汽車解構室 網站`。
6. **關閉**「強化評估」裡不需要的項目也可以(捲動、外部連結、網站搜尋等會多送事件;只想要人數可全關,保留「網頁瀏覽」)。
7. 建立後會看到 **評估 ID(Measurement ID)**,格式 `G-XXXXXXXXXX`。複製它。
   - 之後找法:管理(左下齒輪)→ 資料串流 → 點你的串流 → 右上角「評估 ID」。

## 二、把 ID 放進網站(不需要重新打包)
1. 到你的 GitHub 倉庫 → **Add file → Create new file**。
2. 檔名輸入 `ga-id.txt`(跟 `index.html` 同一層)。
3. 內容只放一行 ID,例如 `G-ABC123DEF4`,不要加引號或其他文字。
4. **Commit changes**。等 Pages 重新部署(約 1~2 分鐘)。
- 要停用整個統計:刪除 `ga-id.txt` 即可。

## 三、驗證有沒有成功
1. 用**一般視窗**(不是無痕、不要開廣告攔截)開正式網址。
2. 開 Analytics → **報表 → 即時**,幾十秒內應看到「過去 30 分鐘的使用者:1」。
3. 開頁面右上「設定」,應看到「匿名流量統計」開關;關閉後重新整理,即時報表不應再增加你這個使用者。
4. 開發者檢查(F12 → Network)搜尋 `collect`,關閉開關後不該再有請求。

## 四、怎麼看人數
- **報表 → 即時**:現在有幾個人。
- **報表 → 獲取 → 流量獲取**或**使用者屬性 → 總覽**:活躍使用者(日/週/月)、新使用者、國家/裝置。
- 「使用者」≈ 不同的瀏覽器/裝置,不是不同的人;換瀏覽器或清除資料會被算成新使用者。

## 五、請注意的限制
- **會被低估**:uBlock、Brave、部分公司網路會擋 Google Analytics,實際人數通常更多。
- claude.ai 預覽、本機開檔都**不會**統計(這是刻意的,避免汙染數據)。
- 若有歐盟訪客,法規可能要求事先同意(cookie 橫幅);目前版本以台灣自學者為主,未做橫幅。若要面向歐盟,請告訴我再加同意機制。
- GA 預設保留事件資料 2 個月(可在 管理 → 資料保留 改為 14 個月)。
- 這是匿名流量統計;請勿在頁面或 GA 內加入可識別個人的資料。
