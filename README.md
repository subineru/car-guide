# 汽車解構室 · 互動 3D 圖解

> **內容未經專業審核。**(頁面頂端的標籤標示為「試作版」。) 這是一個給汽修學習者自學用的互動 3D 教學網頁,可以旋轉整台車、點選區域放大,依序了解引擎、冷卻、充電與起動、離合器與變速箱、轉向、煞車與排氣。

![整車](preview/car.png)

## 怎麼用
- 打開網頁:拖曳旋轉、滾輪縮放,點車頭等位置進入「引擎艙」等區域,或用「發動全流程」看整條動力路線。
- 右上角可切換車殼顯示(實體 / 透視 / 輪廓 / 隱藏)、開關車門與引擎蓋、換車色、開關場景(道路、森林、山)與「行駛預覽」(速度緩慢加到約 5 公尺/秒;車輪轉動、道路向後、車體輕微震動、視野微微拉寬;樹木、路邊物、丘陵與山會不斷隨機生成,不會重複,遠景以較慢的速度移動形成景深),透視模式可顯示學習編號與懸吊。
- 左上說明文字裡的零件名稱可以點,鏡頭會飛過去;標題列的每一層也可以點回去。頂列的「隱藏介面」(快捷鍵 H)可以收起左上說明與右上控制區,方便截圖或展示。
- 每個主題有步驟、滑桿與「上一步 / 下一步 / 整個跑一遍」;學習進度存在**你自己的瀏覽器**裡:「學習面板」依區域與主題列出所有進度:圓圈空 = 未開始、黃色圓餅 = 進行中、綠色 ✓ = 完成(步驟全部播完,而且理解重點全部勾選);可以重置(有「復原」),也可以匯出 / 匯入。整車畫面本身不顯示進度。
- **錄成影片**:每個主題的步驟列有「⏺ 錄成影片」,會把全部步驟錄成 WebM 影片(無聲音,含零件名稱與字幕),需要 Chrome 或 Edge 94 以上;錄製時請不要切換分頁,Esc 可取消。
- **背景音樂**(頂列「♪ 音樂」,預設關閉,音量在設定):輕鬆抒情的跑車風,約 82 BPM,由程式在瀏覽器內即時合成,沒有任何音檔或取樣。
- 建議用電腦或筆電的 Chrome / Edge / Firefox / Safari;平板可以開,但較吃力。

## 內容品質
- 內容與數值多為**示意**,不是特定車款的規格;機構是通用前置橫置四缸前驅手排車。
- 說法逐條對照過 Wikipedia 並標示狀態(已核對 / 部分核對 / 未核對 / 示意值),報告在 [`docs/`](docs/)。Wikipedia 是通用參考,不是原廠手冊;**要用於正式教學或考試,請再對照課本或原廠維修資料。**
- 車殼是手繪風的運動房車造型,**沒有廠徽**,不是任何真實車款的複製品。

## 發佈到 GitHub Pages
1. 在 GitHub 建立新倉庫(Pages 免費版需要**公開**倉庫)。
2. 把這個資料夾**裡面的所有檔案**(包含隱藏檔 `.nojekyll`)上傳到倉庫根目錄。
3. Settings → Pages → Build and deployment → Source 選 **Deploy from a branch**,Branch 選 `main`、資料夾選 `/ (root)` → Save。
4. 等 1–2 分鐘,網址是 `https://你的帳號.github.io/倉庫名稱/`。

## 打開後一片白?
頁面現在會先顯示載入畫面;若瀏覽器沒有 WebGL(例如關閉硬體加速、遠端桌面、被封鎖的顯卡),會顯示原因、處理步驟與可複製的「診斷資訊」,不再是空白。
